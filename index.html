Connect a Supabase database

This makes your progress a real Postgres table, reachable from any browser or device — including this file hosted plain on GitHub Pages, no Claude needed.

  1. Create a free project at supabase.com.
  2. Open the SQL Editor in your project and run the snippet below once.
  3. Go to Project Settings → API, copy the Project URL and the anon public key, and paste them below.
create table public.calendar_days ( date date primary key, done boolean default false, note text default '', links jsonb default '[]'::jsonb, override jsonb, updated_at timestamptz default now() ); alter table public.calendar_days enable row level security; create policy "anon read/write (single-user tool)" on public.calendar_days for all using (true) with check (true);
⚠ The policy above lets anyone with your URL + anon key read/write this table — fine for a personal tracker, but don't commit the URL/key into a public repo. They're saved only in this browser's localStorage when you hit Connect below. Use a private repo, or add real Supabase Auth later, if that matters to you.
